How it works

1. The watchlist is a plain text file in the GitHub repo (watchlist.txt). Either of us can add or remove a ticker with the "Edit watchlist" button.

2. Every weekday evening, and a few minutes after the watchlist changes, a free GitHub job downloads public financial data from Yahoo Finance and runs the three scoring lenses.

3. This page just reads those results. It holds no keys, doesn't connect to any brokerage, and never places trades.

4. "Our portfolio" is stored only in your own browser. Export it to a file to share it or move it to another device.

Limits to keep in mind: free data covers about 4 years of financials, while these investors looked at 10+. The scores are numeric proxies for judgments (moat durability, management quality) that still need a human. Always check the company's own filings before acting.

Independent personal project, not tied to any employer or agency. Public market data only (Yahoo Finance). No internal or personal data.
